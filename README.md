# Iryna Vyshniak - VS Code Portfolio 🫐🍌

A stunning, interactive Visual Studio Code clone portfolio built for a Junior Frontend Developer. This project mimics the complete look and feel of a modern VS Code workspace, featuring the custom **"Blueberry Banana"** theme.

![VS Code Portfolio Screenshot](https://raw.githubusercontent.com/Iryna-Vyshniak/vscode_portfolio/main/screenshot.png) *(Note: Link placeholder)*

## 🚀 Vision
The goal of this project was to create a unique, technical, and immersive experience for recruiters and developers to explore my background, skills, and projects in an environment they are intimately familiar with.

## ✨ Features
- **Realistic VS Code UI**: Complete Activity Bar, Sidebar (Explorer), Tabs, and Editor logic.
- **Blueberry Banana Theme**: A custom deep-purple and neon-highlight theme designed for high contrast and modern aesthetics.
- **Interactive File Explorer**: Navigate through "simulated" file systems including `.jsx`, `.css`, and `.html` files.
- **Syntax Highlighting**: All simulated code editor files feature professional-grade syntax highlighting (React/JSX and HTML).
- **Responsive Design**: Fully functional on desktop and mobile with a custom hamburger menu for smaller screens.
- **SEO & Social Ready**: Optimized with Open Graph and Twitter Card meta tags for professional sharing.
- **Virtual Resume**: A integrated HTML resume viewable directly inside the editor simulator.

## 🛠️ Stack & Tools
- **Core**: Vanilla HTML5, CSS3 (Modern features & variables), and JavaScript (ES6+).
- **Icons**: Hand-crafted SVG icons and Lucide-React font icons.
- **Typography**: Fira Code (monospaced) and system-ui fonts.
- **Build System**: [Vite](https://vitejs.dev/) for fast development and optimized production builds.

## 📁 Project Structure
```bash
├── index.html             # Main entry point & Editor Layout
├── script.js              # Core Editor logic (Tabs, File navigation, Syntax code injection)
├── style.css              # Global styles & Blueberry Banana theme CSS variables
├── metadata.json          # Project name, description & app permissions
├── package.json           # Project dependencies & build scripts
├── vite.config.ts         # Vite build configuration
└── tsconfig.json          # TypeScript configuration
```

## ⚙️ Installation & Development

To run this project locally, ensure you have [Node.js](https://nodejs.org/) installed.

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Iryna-Vyshniak/vscode_portfolio.git
   ```

2. **Navigate to the directory**:
   ```bash
   cd vscode_portfolio
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Build for production**:
   ```bash
   npm run build
   ```
